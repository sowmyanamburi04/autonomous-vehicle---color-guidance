# Autonomous Vehicle Guidance using Color Signals

## Project Description
This project uses Python (OpenCV) and Arduino to control a vehicle using color detection. The system can move forward, backward, turn left/right, or stop based on the color shown to the camera.

## Technologies
- Arduino UNO, NodeMCU
- Python, OpenCV, PySerial
- KNN Classifier

## How to Run
1. Upload the Arduino code.
2. Run `main.py` from Python.
3. Show color objects to webcam.
